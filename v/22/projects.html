Projects

I make web-based software and games in Elixir and PHP, using maybe a little too much JavaScript for my own good. I build everything out in the open; source code is available on GitHub, Codeberg, and Gitz, the awesome Git frontend I wrote in PHP.

Here’s some projects I’m especially proud of:

  • Signo  Experimental compiler for a Lisp-inspired language, written in Elixir.

  • Scatterpubb  Explores ways to blend websites, social media and collaboration on the Web, by implementing an easy-to-use website engine powered by various open standards.

  • Oblikvo  Browser-based 3D first-person shooter with old school graphics and multiplayer support.

  • Vik  What if GitHub gists, AWS Lambdas and Elixir Plugs had a baby?
