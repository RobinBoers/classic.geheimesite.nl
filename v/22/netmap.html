Netmap

Most sites have some sort of Sitemap. A big document or list containing a bunch of links to a bunch of pages on the site. If you’re looking for my sitemap, well that’s too bad, because this isn’t it.

But Robin, what is this then? This is a netmap. It’s not a collection of pages on a site, but rather a collection of sites in a network. My network, to be exact. And in case you were wondering, yup, I made this up myself :)

Hey! If you got redirected here, that’s probably because the site you were looking for doesn’t exist (anymore). Maybe what you’re looking for is in the list below?

If you are looking for a sitemap, it’s right here.

  • dupunkto.org: a hacker collective that I’m co-maintaining.

  • bugs.dupunkto.org: issue tracker for {du}punkto projects.
  • ftp.dupunkto.org: file sharing for {du}punkto members.
  • wiki.dupunkto.org: wiki written by {du}punkto members.
  • docs.dupunkto.org: documentation for {du}punkto projects.
  • school.geheimesite.nl: a bunch of study materials from high school.
  • uni.geheimesite.nl: a bunch of study materials from university.
  • classic.geheimesite.nl: a public archive of older versions of this website.
  • inbox.geheimesite.nl: my public Cipher inbox for receiving sensitive messages.

  • api.geheimesite.nl: REST APIs for several personal projects.

Public services

  • cipher.dupunkto.org: public Cipher instance for securely sending and receiving passphrases and API keys.
  • inv.dupunkto.org: self-hosted Invidious instance; publicly accessible but with no guarantees regarding uptime.
  • rss.dupunkto.org: self-hosted Miniflux (v2) instance shared with various friends and family members.
  • mpv.dupunkto.org: self-hosted Emby server for live-streaming totally-not-pirated movies at sleepovers.

Infrastructure & microservices

  • nym.dupunkto.org: in-house identity provider and authentication layer.
  • vik.dupunkto.org: in-house Vik instance for managing api.dupunkto.org.
  • scry.dupunkto.org: in-house version-control system for various {du}punkto projects.
  • mesh.dupunkto.org: in-house distributed uptime monitoring for {du}punkto servers.

Archived

  • blog.geheimesite.nl: public archive of all content on my old (Blogger) blog; most important posts have later been migrated to my current blog, on this website.
  • micro.geheimesite.nl: public archive of my short-lived microblog running on my own DIY blogging software called neopub.
  • nindo.geheimesite.nl: public archive of all Nindo posts published before the platform went offline in January 2021.
  • cydia.geheimesite.nl: public archive of my Cydia repo hosting popular tweaks for Legacy iOS that cannot be purchased via Cydia anymore.
  • {demo, pages, docs}.geheimesite.nl: unmaintained sites, documentation, and demos hosted on GitHub Pages.
