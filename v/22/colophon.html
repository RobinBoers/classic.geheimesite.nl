Colophon

This site was built using Vygotsky, an esoteric SSG written using the Mix build system. The generated HTML is being hosted over at bHosted and {du}punkto, both here in the Netherlands.

All original content on this website is freely available in the public domain in accordance with the CC0 1.0 Universal license. Download, copy, remix all allowed.

The source code is available on GitHub, Codeberg and Gitz, and is licensed AGPLv3 because I strongly believe in Copyleft.

This site is being served by Caddy. It does HTTP3, SSL, HSTS, CSP, Brotli compression, and indefinite caching for assets and daily caching for content. A robots.txt file is autogenerated nightly with the help of Dark Visitors in a futile attempt to block AI spiders from relentlessly scraping my site.

All markdown written in Neovim, the perfect hammer for an imperfect world. Best viewed in any browser, including Firefox, Netscape Navigator, Internet Explorer and lynx.
